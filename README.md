# Grief Journal — free demo

A free, click-through demo of **Grief Journal & Workbook**, a private offline journal app by SoloStack Creations.

Open the demo: the GitHub Pages address for this repository.

The demo uses a made-up example journal. Nothing you type is saved, and 13 of the 60 workbook pages are open. The full journal is a single file you download from Etsy and keep on your own computer.

Personal journaling tool, not therapy or medical advice.
